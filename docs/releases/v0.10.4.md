# v0.10.4: Review fixes and the monthly update check

**Date:** 2026-11-11
**Built on:** `main`

Two fixes left over from the pre-pilot review (Nov 10), and a way to do the
monthly security check now that GitHub's automatic checks are on hold.

## Password hints never show an earlier password

When the password check warns, each hint shows the few words before the
suspected password, with the password masked: "…my password is S•••••••".
With two passwords close together, the second hint showed the first one in
full:

> Before: …password **Hunter22!** new password S•••••••
>
> Now: …password ••••••• new password S•••••••

Every password the check found is now masked wherever it appears in a hint,
always with 7 dots so its length doesn't show. A hint with only one password
is unchanged.

## A length limit on descriptions and replies

A description, reply or internal note holds up to 20,000 characters, about
ten pages. Over that, the page says:

> That's 23,415 characters, over the 20,000 limit. Attach a long log or list
> as a file instead.

The text stays in the box, so nothing is lost. Email-in already cut an
email's text at 20,000 characters; the web and email now share the one limit.

## The monthly update check

The backlog's "monthly check of dependencies for security updates" now has
its steps, in [deployment.md](../deployment.md) section 11:

1. **The check.** On the server:

   ```bash
   docker compose -f compose.yaml -f compose.prod.yaml exec web python scripts/check_updates.py
   ```

   For each Python package the app runs on, it asks PyPI for known security
   issues in the installed version, and lists the newest release a rebuild
   would install and the latest overall. It also compares the proxy's Caddy
   version with Caddy's latest release. "Known security issues: none." is
   the all-clear.
2. **Refreshing the images.** Updating the app never downloads a newer
   PostgreSQL or Python base image: Docker keeps the ones from the first
   install. The new steps pull PostgreSQL 17's newest release and rebuild on
   the newest `python:3.13-slim`, out of hours.

November's check (2026-11-11): no known security issues in any package;
Caddy 2.11.9 is the latest. gunicorn 27.0 is out, but it isn't a security
fix, so the pin stays at 26.2.
